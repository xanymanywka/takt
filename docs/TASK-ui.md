# TASK: Интерфейс Takt по дизайну «Партитура»

## Цель
Фронт приложения (React 19 + TS + Vite) повторяет утверждённый дизайн
`docs/design/orchestra-hand.html` один в один, в двух темах, и работает в браузере на моках,
а в Tauri — через IPC-контракт `docs/SPEC.md` §7 (ядро пишет другой исполнитель параллельно).

## Объём
- Зависимости: `zustand`, `@xterm/xterm`, `@xterm/addon-fit`. Шрифты Montserrat и Newsreader
  (Google Fonts в `index.html`, у Newsreader `opsz`). Удалить демо-код скаффолда (`App.css`,
  логотипы, счётчик greet).
- `src/styles/tokens.css` — токены **буквально** из `docs/DESIGN.md` (день на `:root`, ночь в
  `:root[data-theme=dark]` и в `@media (prefers-color-scheme: dark) :root:not([data-theme=light])`).
  `src/styles/app.css` — стили компонентов, перенесённые из `<style>` эталона (там всё уже есть:
  `.lead .switch .theme .side .proj .limits .main .top .seg .thread .me .voice .score .stave
  .bars .legend .sats .sat .composer .setnav .start .grp .row .detail .foot .cta`).
  Переключатель темы: `document.documentElement.dataset.theme`, запоминать в `localStorage`
  (`orch-theme`) в try/catch; иконки солнце/луна из эталона.
- `src/lib/ipc.ts` — обёртки `invoke`/`listen` по контракту §7 с типами оттуда.
  `src/lib/mock.ts` — те же функции на мок-данных (две задачи из дизайна: Codex `pty-bridge`
  и Antigravity `terminal-pane`, лимиты 62/41/88 %, проекты из боковой панели, дирижёр отвечает
  репликой из дизайна с задержкой, у `terminal-pane` состояние `asking`). Выбор: если нет
  `window.__TAURI_INTERNALS__` — мок. Фейковые события по таймеру (бегущий шаг, новая строка лога).
- `src/store.ts` (zustand): проекты, активный проект, задачи, лимиты, сообщения дирижёра,
  вкладка (`chat|code|orchestra`), экран (`chat|start`), тема.
- Экраны и компоненты по `docs/SPEC.md` §6 и §8:
  - `Lead` — заголовок «Takt. *Партитура*, а не дашборд.» заменить на название активного
    проекта (голосом) + подпись, справа переключатель «Чат с дирижёром · Старт · Доступы» и тема.
  - `Sidebar` — светофор, проекты (цвет группы, точка активности у проектов с `running`),
    лимиты «Осталось на сегодня» три полоски.
  - `Chat` — сегменты «Чат · Код · Оркестр», шапка «<проект> · ветка», пилюля «N исполнителей»;
    лента: пузырь пользователя, реплика дирижёра (Newsreader 18.5 px) из событий `assistant`
    (текстовые блоки склеивать по `message.id`), события `tool_use` — одной тихой строкой
    (`читает spec/pty.md`, `запускает cargo check`), `result` закрывает ход;
    под репликой `Score` (строка на задачу: имя с цветной точкой, такты = `steps`, статус
    «шаг k из n · <lastLine>») и `Satellite`-карточки (имя, ворктри · модель, состояние с
    точкой, 3 последних строки экрана, «Дальше: <первый невыполненный шаг>», блок «Спрашивает:»
    с полем ответа и кнопками-чипами, футер «шаг k из n · Дифф · Терминал»). Клик «Терминал» →
    вкладка «Код» в этой ворктри. `Composer` — стеклянная строка, ⌘↵ отправляет.
  - `Code` — список ворктри слева (из задач), `Terminal` (xterm + fit) через `pty_*`; в моке —
    локальный эхо-терминал.
  - `Orchestra` — таблица всех задач: проект, исполнитель, состояние, шаги, начато, кнопки
    «Ответить», «Остановить».
  - `Start` — экран «Старт · Доступы» из эталона: навигация шагов слева, группы «Инструменты»
    (найден/вход/аккаунт), «SSH-хосты», «MCP», раскрывающиеся строки (`.row.open .detail`),
    внизу заметка и CTA «Создать INSTRUCTIONS.md» (вызов `write_instructions`) и «Открыть
    терминал» (`open_in_terminal`).
  - `Icons` — рисованные SVG из эталона, штрих 1.5 px. Никаких иконочных библиотек.
- Состояния: пустой проект («Дирижёр ждёт первой задачи»), ошибка команды (строка под
  композером, цвет `--warn`), нет входа в `claude` (карточка с кнопкой «Открыть терминал»).
- Доступность: фокус `outline:2px solid var(--acc)`, `prefers-reduced-motion`, `aria-label` у
  иконочных кнопок, контраст и кегли строго по `docs/DESIGN.md` (у владельца слабое зрение —
  **ничего мельче 12.5 px, вторичный текст ≥ 7:1**).
- Окно: макет резиновый от 980 px ширины, боковая панель 220 px, спутники в две колонки от
  1100 px и в одну ниже.

## Контекст
- `docs/design/orchestra-hand.html` — эталон: открыть в браузере, переключить тему, смотреть
  оба экрана (в файле экран Start скрыт атрибутом `hidden` на `#start`, поменять вручную).
  Весь CSS эталона можно переносить почти дословно, заменяя `.win` на корневой макет окна
  (без масштабирования `fit()` — в приложении 1:1).

- Формат событий `claude --output-format stream-json`: строки JSON с `type` ∈
  `system|assistant|user|result`; у `assistant` поле `message.content[]` с блоками
  `{type:'text',text}` и `{type:'tool_use',name,input}`. Документацию по Tauri `invoke/listen`
  брать через Context7 MCP.
- Проверять в браузере: `pnpm dev` → http://localhost:1420, обе темы, ширина 980 и 1400.
- Если упрёшься в лимит — `docs/HANDOFF-ui.md` (что сделано, что осталось, как проверить).
