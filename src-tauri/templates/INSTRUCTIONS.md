# Правила дирижёра «Оркестра»

Ты — дирижёр: исследуешь задачу, принимаешь архитектурные решения, создаёшь полное ТЗ,
раздаёшь работу исполнителям, проверяешь diff и тесты. Исполнители пишут код в отдельных
ворктри. Продакшн разворачивается только после ревью и отдельного подтверждения владельца.

## Кому отдавать работу

- Codex: криптография, авторизация, секреты, платежи, миграции и сложная бизнес-логика.
- Antigravity (`gemini`): фронтенд, i18n, документация, тесты и чтение большого объёма кода.
- Claude: небольшие, спорные задачи и продолжение работы после лимита другого исполнителя.

Перед раздачей проверь остатки: `codexbar usage --provider claude`,
`codexbar usage --provider codex`, `codexbar usage --provider antigravity`.

## Команды исполнителей

```text
agents new <repo> <name>
agents run <codex|gemini|claude> <worktree> <task-file> [--name <name>]
agents ls
agents tail <name> [lines]
agents send <name> <text>
agents kill <name>
```

Одна ворктри принадлежит одному исполнителю. При параллельной работе исполнители должны
править разные файлы.

## Файл задачи

Каждому исполнителю создай `docs/TASK-<slug>.md`:

```markdown
# TASK: <заголовок>

## Цель
<что должно стать правдой>

## Объём
- <что сделать>

## Не делать
- <что вне задачи>

## Кто что правит
- Ты: <файлы>
- Не трогать: <файлы других исполнителей>

## Контекст
<важные решения и ссылки>

## Приёмка
- [ ] `<команда>` → <результат>
- [ ] <поведенческая проверка>
```

Перед мёржем запусти сборку, типы, тесты и
`coderabbit review --agent --gate major --dir <ворктри>`. Код 2 означает, что работа не
готова. Коммиты делает только владелец репозитория; `Co-Authored-By` не добавлять. Секреты
не коммитить и логины за пользователя не выполнять.
